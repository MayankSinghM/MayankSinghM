## 🚀 Featured Projects

### 🤖 AI Coding Agent

A Codex-inspired AI coding agent that analyzes Python repositories, builds a
project index using AST, identifies relevant files based on natural-language
requests, generates code using an LLM, parses the generated response, validates
the code, and automatically updates the project.

**Tech:** Python · AST · LLMs · Groq API · FastAPI

**Key Components:**
- Repository/File Reader
- Python AST-based Project Index
- Intelligent File Planner
- Context Builder
- LLM Prompt Pipeline
- Structured LLM Response Parser
- Syntax Validation
- Automatic File Modification

### 🧊 Voxel Engine

A Minecraft-style voxel engine built from scratch with Python and OpenGL-based
rendering.

**Tech:** Python · ModernGL · Pygame · PyGLM · NumPy · OpenGL

**Key Concepts:**
- 3D rendering pipeline
- Vertex & Index Buffers
- GLSL shaders
- Camera & view transformations
- Projection matrices
- Depth testing
- Voxel world generation
